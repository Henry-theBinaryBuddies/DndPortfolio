Side Quest (Adventurer Anvil):

The core: a character file that stores only the choices made (plus DM rulings and a roll log), a small set of generic choice kinds (pick one, pick several, assign, allocate, roll), and one function that recalculates the whole character from the file. Dice notation like 4d6kh3 is parsed and rolled with every die kept. To prove the core doesn't secretly depend on D&D, Claude wrote a made-up gardening game that only the tests use, and ran it through the core.
