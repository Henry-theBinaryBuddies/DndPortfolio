Artifact 5 (Tome & Tile):

I finished my second-milestone work. Both were fixed before it merged.

Side Quest (Adventurer Anvil):

Characters now save themselves in the browser half a second after each change, and can be downloaded and opened again as files. Every file is checked before it opens, so one from a newer version of the app, another game or a damaged download is refused with the reason. If the same character is open in two tabs and one of them saves, the other stops saving until I choose which copy to keep. A test at phone size found that the save status and the Characters button were hidden there.

Then levels 1 to 20 and multiclassing. The SRD pack already had every class's levels, so the work was in the rules: the first class keeps the levels the others don't take, only it gives saving throws, each class's score prerequisites are checked (a DM can allow one that isn't met), hit points take the average after 1st level, and two spellcasting classes share the multiclass slot table while a warlock's Pact Magic stays separate. Ability Score Improvements, Eldritch Invocations with their prerequisites, Mystic Arcanum and Magical Secrets all became choices. Claude's design note had one slot count wrong for a Paladin 3 / Sorcerer 3; the table the code uses has it right, and a test checks it. A Level up button now sits on Review and on each saved character.

Next came the optional rules, on a new Rules step: a feat instead of an Ability Score Improvement (the SRD has only one, Grappler, entered from its text), rolled hit points with every roll kept and rerolls noted, variant encumbrance, and moving a race's ability increases to other scores. Variant Human isn't in the SRD, so a pack can mark a race as needing the feats rule, ready for my own.

Last, the character sheet, on screen and for printing: two pages with the ability scores, saves and skills marked for proficiency, the combat numbers, features with the level they come from, spells by level and the character's story, then any DM rulings and the SRD credit. It prints black on white without the app around it. Its tests caught two things on the way: the features list had no text for the full-text print option, and some comments in the core used game words, which a test forbids so that the core stays game-agnostic.

I merged all of it to master. 263 unit tests and 43 browser tests pass, with accessibility checked at desktop and phone sizes. Three smaller pieces of the first milestone are left: an inventory editor, a session journal and a written guide to the pack format.
