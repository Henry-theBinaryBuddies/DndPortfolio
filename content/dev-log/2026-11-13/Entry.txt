Artifact 5 (Tome & Tile):

This was the first day of real code, and I changed how the work gets done. Claude (Fable) writes a short brief for each piece, a cheaper Claude (Sonnet) writes the code, and Fable reads every change and re-runs the checks before anything is merged. I approve each new library one at a time, and when I did not know what one was I asked Claude to explain it first.

First the dice engine. It reads notation like d20+5 and 2d20kh1+5, rolls fairly (it rerolls instead of using a remainder, which would favour low numbers), handles advantage and disadvantage, and doubles the dice on a critical hit. For the 3D dice animation later I decided on the dice-box library, which is already used on this portfolio. Then the server. Players can move their own tokens, chat and roll, and the GM can hand a token to a player. Before any message goes out, the server removes what that viewer must not see: hidden tokens, a monster's hit points and GM-only rolls. A first Sonnet session started in the wrong folder, wrote nothing and was relaunched. I approved two more libraries so the server's socket loop could be tested with real clients, which added 19 tests: a rejection reaches only the sender, a hidden roll reaches only the GM, and a client that stops reading is dropped.

Then the map. The renderer draws a grid and tokens in the browser, and you drag a token to move it. The token snaps to the grid, and it only really moves when the server says so. Claude opened it in a browser against the real server, dragged a token, and the move came back from the server. Next came the join token for video calls: the server hands each person a signed pass that lets them into the call room, and spectators can watch but not speak. It works as far as its tests go, but I have not made the LiveKit account yet, so no real call server has ever accepted one of these passes.

Last, a check that the web page builds in CI, and the first weekly report for the class. It is written from the pull requests, the dev logs and the decision records, and it says plainly what is not done: the LiveKit account, and my teammates' first pieces still waiting for review.
Side Quest (Adventurer Anvil):

All 12 classes and their subclasses. The level-1 features that change numbers are calculated (Rage, Unarmored Defense, Second Wind, Lay on Hands), along with hit points and expertise. Then the Background step with the Acolyte: personality written freely, with the background's tables offered as suggestions, and the 2014 rule that a skill given twice (by your race and your background, say) is swapped for another of your choice.
