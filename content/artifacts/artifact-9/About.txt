Side Quest

Scenic Sorcerer

A free map maker for tabletop role-playing games, built to answer what players say is wrong with the tools they already use: exports that are only a flat picture, hex grids that do not line up when the map reaches the tabletop, maps locked to the size they were started at, paywalls and accounts, AI art, and editors that only work online. It runs in the browser with no account, keeps a map in the browser and in a file you save, and uses no AI.

Draw on a square grid or a hex grid (flat-top or pointy-top). Rooms can be rectangles, circles, triangles or any shape drawn corner by corner. Select one and round dots on its corners reshape it, so a triangle can be made obtuse and a corner added or taken away, while square handles stretch it, so a circle becomes an oval. Walls are optional per room, so a pond or a garden is just floor. Doors and windows snap onto walls, curved ones included, and travel with their room. A brush paints the floor textures freehand. Stamps are pictures you add yourself (PNG, JPG, WebP, GIF or SVG), kept in the browser: scatter them, then move, turn, resize, flip, tint and shadow them. Text has preset looks for room names, regions and seas, with fonts, colour, halo and letter spacing. A separate GM layer holds room numbers that count up by themselves, traps, secret doors and notes, and switching it off shows what players will see.

Lights (candle, torch, lantern, magic glow, daylight, or any colour) drive a lighting preview: the map goes dark except where light reaches, walls and doors stop it, and windows let it through. A map can have several levels, with the level below shown faintly for lining rooms up.

Export is the point. A picture can be saved as PNG, JPG or WebP at up to 8192 pixels, sized so a hex map lines up with the tabletop's grid without nudging. For virtual tabletops it writes a Universal VTT file and a Foundry scene, carrying the walls, doors, windows and lights, so nothing has to be redrawn. Both were checked for form, and the pictures were checked pixel by pixel, but neither has been imported into a real tabletop yet, so the first real import may need small fixes.

Built with TypeScript and Vite, drawing on an HTML canvas with no runtime libraries, and 144 unit tests. Maps are stored as vector data, so they can be exported at any size. The stamp library starts empty. Regional, town and hex-crawl modes, map generators and a printable PDF are still to come. It is set up to be hosted as a static site on Cloudflare Pages, with a security policy that lets the page load only its own files.
