# Built-in content packs

Data only, loaded by the app at run time through the same checks as anyone's own packs (see `src/app/packs.ts`).
`srd-5.1.pack.json` is made by `npm run import:srd` from the pinned files in `data/srd-5.1/raw`; don't edit it by hand.

How to write a pack: [`docs/PACK-FORMAT.md`](../../../docs/PACK-FORMAT.md). The JSON Schema it follows is in
[`../schemas/`](../schemas/).
